1、项目背景
想做一个报价工具，覆盖滑块袋、OPP/CPP袋和夹链自封袋三种产品。我理解通常的报价思路是首先计算出生产所需要的所有的原料成本、然后工厂根据实际情况加上水电、房租、人工这些成本，再加上期望的利润，就是最后的报价。
但是目前的实际情况是，我们是一家新的工厂，开工率不足，工人熟练程度也不高，按照正常的思路报价，根本没有优势。所有我想做的报价系统，可提供以下三组报价策略共选择。
a.取名“参照报价”。在计算出生产所需要的所有的原料成本的基础上，参考客户其他的供应商的报价单，因为这个价格是客户接受过的。然后将我们的成本带入，看成本占报价的一个大致比例。希望系统能够根据占比的统计学结果，外加我们的成本，倒推出得到我们的报价。
b.取名“行业报价”。在计算出生产所需要的所有的原料成本的基础上，结合工厂自身的真是情况报价。这个目前比较难，数据也欠缺，可以后边跟进。
c.取名“自由报价”。在计算出生产所需要的所有的原料成本的基础上，提供输入框填写加的比例，由使用者根据情况自行输入，后算出报价。

目前已提供以下资料
1、滑块袋、OPP/CPP袋和夹链袋的原料成本计算公式和默认价格。
2、滑块袋、OPP袋和夹链袋其他工厂的报价样本，用于报价策略a。

当前产品覆盖：滑块袋、OPP/CPP袋和夹链自封袋。夹链袋可选择单筋条或双筋条，重量按对应实测样本及规格拟合模型估算，并按筋条数、印刷色数、厚度和袋面积匹配工厂报价样本。OPP参照报价会按胶条状态、接近厚度和尺寸匹配报价样本；小尺寸袋的原料成本占比较低，因此不能用所有尺寸混合后的统一占比。CPP成本公式已接入，但当前供应商报价样本只有OPP，CPP参照报价待补样本。
